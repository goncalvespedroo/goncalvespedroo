## Atualmente construindo: Sokra

O Sokra é um tutor de estudos baseado no método socrático.

Em vez de simplesmente entregar respostas, o sistema conduz o estudante
por meio de perguntas, identifica dificuldades recorrentes e constrói
uma memória personalizada do processo de aprendizagem.

- Tutor socrático com IA
- Memória persistente do estudante
- Next.js, TypeScript e Python
- Produto desenvolvido em público
- MVP em desenvolvimento

[Conheça o projeto](https://github.com/goncalvespedroo/sokra-tutor)


[Visite a landing page](https://sokra-landing.vercel.app/)
